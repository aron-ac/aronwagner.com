Using the attached illustration as the art style reference (same hand-inked cartoon look, line weight, soft shading and colors), draw a sheet of 5 tall pieces of data center equipment for a side-scrolling video game.

- Draw every object from straight in front (front view, facing the viewer, not at an angle), like the back wall of a side-scrolling game. All five at the same height and the same scale, standing on the same invisible ground line.
- 5 objects in one row, evenly spaced, each filling the full height of the image, not touching:
  1. A tall black server rack with its glass door closed, rows of servers visible inside, small dark status lights on each server (lights off).
  2. The same server rack with its door swung open, servers pulled halfway out, and a messy tangle of blue and yellow network cables.
  3. A tall black network rack full of switches with neat bundles of blue cables running up into the top.
  4. A tall grey computer-room air conditioning unit with vents and a small blank control panel.
  5. A heavy grey data center door with a narrow window and a push bar, set in its frame.
- No logos, no brand names, no text or numbers anywhere.
- Transparent background. No floor, no shadows, no borders, no grid lines.
- Wide image, 1536×1024.
