# Fonts

Self-hosted font files downloaded from Google Fonts on 2026-09-25:

- [Merriweather](https://fonts.google.com/specimen/Merriweather), light / 300: introduction and body text.
- [Caveat Brush](https://fonts.google.com/specimen/Caveat+Brush): illustrated labels and section titles.
- [Caveat](https://fonts.google.com/specimen/Caveat): handwritten name.

Each font's SIL Open Font License is included alongside its font file. License sources are the corresponding `ofl/merriweather`, `ofl/caveatbrush`, and `ofl/caveat` directories of https://github.com/google/fonts.
