# Bitmotive logo

`bitmotive-logo.svg` is the unmodified official logo used by the Bitmotive website header.

- Source: https://bitmotive.com/logos/logo.svg
- Referencing page: https://bitmotive.com/
- Retrieved: 2026-09-27
- Intrinsic dimensions and viewBox: 327 × 78
- Colors: green `#009951` and near-white `#FBFBFB`
- Intended presentation: transparent over a dark background; the “MOTIVE” lettering is near-white.

All lettering is vector path data, so no font download is required.
